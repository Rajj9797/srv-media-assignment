# HTML/CSS/JS Starter Project

This workspace is set up with a simple static web project using:

- `index.html` — page structure
- `styles.css` — page styling
- `script.js` — interactivity with JavaScript

## How to use

1. Open `index.html` in your browser.
2. Edit `index.html`, `styles.css`, or `script.js` to build your project.
3. Refresh the page in the browser to see changes.

## Quick start

- Open the folder in VS Code.
- Use the Live Preview or Live Server extension if you want automatic reload.
